# Análise e Tratamento de Dados com Python

## 📌 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de realizar o tratamento, a padronização e a análise de uma base de dados utilizando Python.

A proposta foi explorar os dados e permitir extrair diferentes perspectivas a partir da base.

---

## 🛠️ Tecnologias e ferramentas utilizadas

- Python
- Google Colab
- Base de dados : Excel e arquivo extraído no Portal da Prefeitura de São Paulo
- Inteligência Artificial como ferramenta de apoio

---

## 📂 Etapas desenvolvidas

O projeto foi desenvolvido a partir de diferentes etapas de exploração e análise dos dados:

### Leitura e exploração das bases

- Importação e leitura dos arquivos utilizados.
- Identificação de inconsistências ¹
- Identificação das informações disponíveis nas colunas.
- Exploração da estrutura e das características da base.

> **Nota/Observação:**
> ¹ Durante a exploração das bases, foi identificado uma  diferença na forma de representação dos nones das subprefeituras entre a base de livros da aplicação e a base geográfica da Prefeitura.
> Por exemplo, a base de livros utilizava "Sao Miguel" e a base geográfica apresentava "São Miguel".
> A partir dessa inconsistência, a IA ajudou a criar uma coluna auxliar que padronizasse esses nomes (python)



### Análise geográfica

- Exploração dos dados geográficos disponíveis em formato GeoJSON.
- Construção de uma visualização em mapa para representar espacialmente.

Esta foi uma das primeiras experiências com a construção de mapas utilizando Python. Para compreender o processo, foram utilizados materiais disponíveis na internet, incluindo uma videoaula, além do apoio de Inteligência Artificial na estruturação do código e na identificação e resolução de erros encontrados durante o desenvolvimento.

### Análise estatística e previsão

- Aplicação de técnicas de análise estatística e modelagem para explorar o comportamento dos dados.
- Utilização do `statsmodels` para construção de um modelo de previsão (*forecast*).

Nesta etapa, a Inteligência Artificial também foi utilizada como ferramenta de apoio para compreender a estrutura do modelo, adaptar o código ao conjunto de dados e solucionar dúvidas relacionadas à implementação.
