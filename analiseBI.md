# Dashboard de Indicadores — Power BI


## 📌 Sobre o projeto

Este projeto apresenta um dashboard desenvolvido no Power BI após a extração dos dados da aplicação do TrocaLivroSP. Lembrando que são dados sintéticos para simulação.

O objetivo foi transformar os dados em indicadores e visualizações.

---

## 🛠️ Tecnologias utilizadas

- Power BI
- Base Excel
- Modelagem de dados
